# career-assistant
A smart career assistant built with Python and Flask that analyzes personality, skills, and resumes to suggest personalized career options.

## 🚀 Features
- Personality quiz for career matching  
- Career suggestions with recommended skills and learning resources  
- Resume analyzer and skill tracker  
- Built with Python (Flask), HTML, CSS, and JSON
