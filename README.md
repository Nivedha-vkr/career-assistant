
Career AI Assistant

1. Overview
The **Career AI Assistant** is a web-based application developed using **Python (Flask framework)** that helps users discover suitable career paths based on their personality traits, skills, and interests. This project is designed to guide students and job seekers in identifying the right career options by analyzing their responses to a personality quiz, resume content, and tracked skill data.

2. Objectives
The main objective of this project is to provide **personalized career guidance** using an interactive, AI-assisted approach. By integrating personality-based quizzes, skill tracking, and resume analysis, the system offers customized career suggestions, required skills, and learning resources to help users prepare for their chosen paths.

3. Key Features
- **User Authentication**: Secure login and registration system for each user.  
- **Personality Quiz**: Determines the user’s preferences and work style to suggest suitable careers.  
- **Career Suggestions Module**: Displays the most compatible career options based on quiz results, including necessary skills and resources for learning.  
- **Skill Tracker**: Allows users to add, view, and manage skills they have learned or wish to improve.  
- **Resume Analyzer**: Extracts and evaluates the user’s uploaded resume to identify missing or relevant skills.  
- **User-Friendly Interface**: Simple and intuitive navigation with visually organized sections.

4. Technologies Used
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask Framework)  
- **Database**: SQLite  
- **Libraries and Tools**:  
  - PyPDF2 (for reading resumes in PDF format)  
  - python-docx (for analyzing Word documents)  
  - Werkzeug (for password encryption and security)  

5. How the System Works
1. Users register and log in to their account.  
2. They select a preferred track (Tech or Non-Tech) and complete a short personality quiz.  
3. Based on their answers, the system generates a list of top career suggestions with required skills and resources.  
4. Users can upload their resume for automated analysis to get feedback on missing skills.  
5. The skill tracker module helps users monitor their progress in acquiring new skills.

6. Usefulness of the Project
This application serves as an intelligent career guidance tool that:
- Helps individuals make informed career decisions.  
- Bridges the gap between skills and job requirements.  
- Encourages self-assessment and continuous improvement.  
- Can be used by educational institutions for student career planning or by individuals for personal career development.
